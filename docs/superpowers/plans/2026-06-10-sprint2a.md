> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the Neo4j Knowledge Graph (ISO 14224 BB1 ontology + plant hierarchy skeleton + read-only `kg.*` MCP), the PI AF crawler connector (`asset_hierarchy.*`), the deterministic pattern-rule registry, and a uniform health-check surface on every live connector.

**Architecture:** New `packages/kg` workspace member (Neo4j 5 driver, forward-only Cypher migration runner, FastMCP server in the MAR-server style). New `packages/connectors/asset_hierarchy` connector that crawls the existing PI AF simulator REST surface. **Tech Stack:** Python 3.12, uv workspace, FastMCP 3.4, neo4j Python driver 5.x, httpx, Pydantic v2, pytest (asyncio auto), go-task, Docker compose (Postgres 16 + Neo4j 5 community).
